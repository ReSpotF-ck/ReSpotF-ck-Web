Alpha/Beta Version
This application is still in development. Some features may not work as expected.

Updates & Changelog

Latest Changes

  • Renamed main player page from N3K0.html to h0m3.html.
  • Fixed real music display by enabling Audius, Jamendo, YouTube, and Spotify searches with demo fallback.
  • Added a Theme settings tab: Default Dark, AMOLED, accent colors, and compact player.
  • Improved mobile and desktop flex layout so the player no longer gets cut off.
  • Added new info pages: DMCA, Notice, Privacy, Help/FAQ, and Updates.
  • Added a sitemap section to the music player sidebar.
  • Added new 404 page with quick links back to the app.

Known Issues

  • Jamendo requires a valid Client ID configured in Settings.
  • YouTube and Spotify playback require your own API credentials.
  • Some downloads may fail due to CORS restrictions from third-party sources.
  • Visualizer is hidden while the player is visible; this will be addressed in a future update.

Coming Soon

  • Light theme option.
  • More detailed player visualization.
  • Improved playlist import/export and sync options.
  • Custom background patterns and more theme customization.
