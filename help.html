Help & FAQ

How do I access the music player?

Open h0m3.html and solve the puzzle. The current answer is the result of the displayed math question. Press Shift+B or open h0m3.html?bypass=1 for the admin bypass.

Why is no music showing?

Make sure you are running the site through a local server (e.g., python -m http.server 8080) rather than opening the HTML file directly. Audius is searched by default and does not require a key. You can also add API keys in the player Settings for Jamendo, YouTube, and Spotify.

How do I add API keys?

Click the Settings (cog) icon in the top right of the player, go to the API Keys tab, and enter your credentials. Jamendo, YouTube, and Spotify require valid Client IDs and/or API keys. Audius works without configuration.

Can I customize the look?

Yes. Open the player settings and select the Theme tab. You can switch between Default Dark and AMOLED modes, change the accent color, and enable a compact player bar.

Can I download music?

The downloader can attempt to save tracks when the source provides a direct audio URL. Some sources are restricted by CORS or require special permissions. Demo tracks can usually be downloaded directly.

Where is my data stored?

All of your settings, liked songs, playlists, and queues are saved in your browser's LocalStorage. No data is sent to our servers. Clearing your browser data will remove your saved content.
